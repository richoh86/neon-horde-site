# Neon Horde: Survivor Roguelite — marketing site

The three-page site for **Neon Horde: Survivor Roguelite**, a one-thumb survivor roguelite for
iPhone: your weapons aim and fire on their own, a boss arrives every two minutes, and a full run is
over in eight. It is free, plays offline, and the only ads are two rewarded videos you can choose to
watch on the results screen. The site is live at
<https://richoh86.github.io/neon-horde-site/> — home, [support](https://richoh86.github.io/neon-horde-site/support.html)
and [privacy policy](https://richoh86.github.io/neon-horde-site/privacy.html) — and the game itself
is on the App Store at <https://apps.apple.com/app/id6795572298>. Static HTML with inline CSS, no
build step, served by GitHub Pages from `main`.
